
# SLA Reporting & Dashboard Automation | SQL, Excel & VBA Automation

## Project Overview

Developed an interactive Excel dashboard to monitor Service Level Agreement (SLA) performance, analyze ticket trends, and track compliance across operational dimensions. Integrated VBA automation to enable dynamic SLA threshold indicators, dashboard refresh, and PDF report generation.

## Tools & Technologies

- **Microsoft Excel:** PivotTables, slicers, KPI cards, charts, and dashboard design
- **VBA (Visual Basic for Applications):** Event-driven automation, conditional formatting, dashboard refresh, and PDF export

## Key Features

- **Interactive Dashboard:** Analyzes SLA compliance, ticket impact, priority distribution, and regional performance using interactive slicers and visualizations.
- **Dynamic SLA Monitoring:** Uses VBA to change KPI font colors based on a 94% SLA compliance threshold—red below 94% and green at or above 94%.
- **Dashboard Refresh Automation:** Implements VBA macros to refresh dashboard data, update calculations, and record the last refresh timestamp.
- **Automated PDF Export:** Exports the dashboard worksheet to PDF for convenient reporting and sharing.

## Technical Implementation

1. Organized ticket data and created PivotTables to support SLA performance analysis.
2. Built dashboard visualizations and slicers to enable interactive filtering and monthly performance monitoring.
3. Developed event-driven VBA procedures to update SLA KPI colors in response to PivotTable changes.
4. Automated dashboard refresh and PDF export through user-triggered macros.
